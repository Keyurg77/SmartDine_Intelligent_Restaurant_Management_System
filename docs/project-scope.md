# SmartDine Project Scope

## Project Title

SmartDine: An Intelligent Restaurant Management System

## Client Scenario

SmartDine is designed for a small restaurant that needs a secure web
application to manage its menu and customer food orders.

## Included Modules

- User registration and login
- Admin and customer roles
- Menu categories
- Menu items
- Food order creation
- Order item details
- Order status management
- Menu search and filtering
- Activity logging
- SmartDine Assistant chatbot

## Excluded From Current Version

- Table reservations
- Table allocation
- Delivery tracking
- Online payment
- External AI API integration

## Intelligent Feature

SmartDine Assistant is a rule-based chatbot that answers questions about:

- menu availability
- food categories
- how to place an order
- order status
- restaurant support information

The assistant will use keyword and intent matching, local rules, and selected
database queries. Users stay in control because the chatbot only provides
information and suggestions.
