# Final Submission Checklist

## Repository

- [ ] Main branch contains latest merged setup, backend, frontend, chatbot, database, and docs.
- [ ] README includes setup/run instructions.
- [ ] `.env.example` is present.
- [ ] No real passwords or secrets are committed.
- [ ] Branches and pull requests show collaboration evidence.

## Application

- [ ] React frontend runs locally.
- [ ] Express backend runs locally.
- [ ] MySQL database can be recreated using schema and seed files.
- [ ] Menu browsing/search/filter works.
- [ ] Ordering workflow is demonstrable.
- [ ] Admin screen is demonstrable.
- [ ] SmartDine Assistant responds to menu/order questions.

## Documentation

- [ ] Project proposal is included or submitted separately.
- [ ] Database design notes are included.
- [ ] Security and risk register is included.
- [ ] Test cases are included.
- [ ] AI feature appendix is included.
- [ ] Presentation outline is included.
- [ ] Evidence screenshots are collected separately and inserted into final report/slides as needed.
